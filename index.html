    Optional: import or export JSON settings

    Import applies a validated ORB configuration to Futures Trading or saves a quant preset for the imported-strategy selector. Export writes the active settings as reusable JSON. JSON never executes code.

    SUPPORTED STRATEGY SOURCE IMPORT

    The ORB NQ Trio Pine source is parsed for its input controls and three preset tables, then mapped to the dedicated MNQ simulator; Pine code is not executed. Other Pine files use the safe subset: supported indicators, crossover signals, and conditional entry/close orders. Unsupported Pine code is rejected. Python and C++ run locally using the on_bar interface: return buy, sell, or hold from completed OHLCV bars. C++ requires g++. Other frameworks need adaptation to this interface.

    Download runnable examples: Python · C++ · Pine. Run algorithm validates, activates, and simulates your source in one step.
